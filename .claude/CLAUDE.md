# Instructions permanentes — Syllabis

## Skills marketing actifs

Ce projet dispose de deux skills marketing installés dans `.agents/skills/` :

- `page-cro` — à utiliser pour tout audit, analyse ou optimisation de page orientée conversion
- `copywriting` — à utiliser pour toute rédaction ou réécriture de contenu marketing

## Comportement attendu sur toute demande marketing

1. Lire `.agents/product-marketing-context.md` en premier, sans exception
2. Charger et appliquer le skill `page-cro` pour les audits de landing page, analyses de conversion, diagnostics CTA, structure de page
3. Charger et appliquer le skill `copywriting` pour toute rédaction de titres, sous-titres, descriptions de features, textes de boutons, FAQ, micro-copy
4. Ne jamais reposer de questions sur le produit si la réponse se trouve dans le fichier contexte
5. Appliquer les deux skills simultanément quand la demande touche à la fois à la structure et au contenu
